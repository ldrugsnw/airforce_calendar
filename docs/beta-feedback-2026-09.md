# 2026-09 베타 피드백 분석과 개발 로드맵

## 조사 개요

- 응답: 7명, Android Chrome·Samsung Internet과 iPhone Safari 포함
- 보유 휴가 등록 난이도: 평균 4.43/5
- 달력 휴가 일정 등록 난이도: 평균 4.0/5
- 재사용 의향: 평균 4.14/5
- 원본: [Google Sheets 베타 설문](https://docs.google.com/spreadsheets/d/1GnA9sCjd2ptuS4EZx7_U4f1-rq1mfYFK67laRKDaR34/edit?usp=sharing)

응답자의 이름은 저장소에 옮기지 않고 의견을 익명 집계했다. 달력 일정 등록은 평균 점수는 높지만 1점 응답과 조작 혼란이 반복되어 최우선 개선 영역으로 판단했다.

## 확정한 개선

1. 휴가 종류를 드롭다운 대신 한 번에 선택하는 라디오 칩으로 표시한다.
2. 획득 일수는 직접 입력과 `− / +` 버튼을 함께 제공하고 1~365일로 제한한다.
3. 획득일은 선택 항목으로 바꾸고, 미래 획득 예정을 포함해 2000-01-01~2999-12-31을 허용한다.
4. 휴가와 외출 등록 모드를 날짜 선택 전에 명시적으로 나눈다.
5. 달력은 각 단계의 다음 행동을 안내하고, 보유 휴가가 없으면 등록 화면으로 이동한 뒤 선택한 날짜로 복귀한다.
6. 날짜 이동과 오늘 버튼을 제공하고 전체 달력 범위를 2000~2999년으로 제한한다.
7. 위로휴가는 라이트·다크 모드에서 노란 배경과 글자가 충돌하지 않는 전용 색상을 사용한다.
8. 홈에 오늘 6개월 전 이상, 오늘 6개월 후 미만의 정확히 12개월 휴가 잔디를 표시한다. 예정된 미래 휴가도 포함한다.

## 조사 후 구현할 항목

- 공휴일: 한국천문연구원 특일 정보를 기준으로 연도별 데이터를 검증한 뒤 표시한다. 표시만 추가하고 휴가 일수 계산에서는 제외하지 않는다.
- 공군 기본 휴가: 국방부 법령과 공군 공식 지침으로 명칭·일수·적용 조건을 확인한 항목만 등록 후보로 제공한다. 사용자가 수정·제외한 후 일괄 추가하며 이후 정책 갱신이 사용자 기록을 덮어쓰지 않는다.
- 복합 휴가: 현재의 독립 기록 구조를 유지하고 `기간 내 일수 배분`, `날짜별 지정`, `연속 등록 단축` 프로토타입을 비교한 뒤 구현 방식을 정한다.

## 후순위 백로그

- 남은 외출 개수
- 홈 화면 추가/PWA 설치 안내
- 가족·친구 읽기 전용 공유
- 앞뒤 달 미리보기
- 여러 달력 버전은 현재 구현하지 않음

## 재검증 기준

- 신규 테스터 80% 이상이 별도 설명 없이 첫 휴가 일정을 저장한다.
- 달력 등록 난이도에서 1점 응답이 재발하지 않는지 확인한다.
- iPhone Safari, Android Chrome, Samsung Internet에서 320~430px 화면과 다크 모드를 확인한다.
